Rest, pause and exercise swaps: using Tonus during a workout

A countdown, a rest interval and a paused workout behave differently. Knowing which one is on screen helps you continue a session without restarting it or changing the wrong interval.

Read the current exercise first

During a timed exercise, the circle shows the time remaining for that interval. In a workout based on sets and repetitions, the screen instead shows the current set and the prescribed repetitions. Finish the set and use the completion button to move on; the app does not count repetitions for you.

The written technique instructions stay on the workout screen. Opening an exercise video pauses the workout clock so that the demonstration does not use up the exercise interval. Resume the workout when you are ready to continue.

The rest buttons start a fresh countdown

On the rest screen, the 30, 60 and 90-second buttons set the remaining rest to that duration from the moment you tap. They do not add that many seconds to the time already left.

For example, if 20 seconds remain and you tap 60 seconds, the display starts counting down from 60. The Skip button ends the current rest interval and moves to the next set or exercise. These controls are disabled while the session is paused; resume it before changing or skipping rest.

Pause when you need an interruption

Use Pause to stop the current countdown, then Resume to continue with the time that was left. This is different from extending rest: pausing preserves the interval instead of replacing its duration.

Time spent paused is excluded from the workout duration saved by Tonus. If you spend two minutes reading an instruction while paused, those two minutes are not added as active session time. An open workout is not saved as completed merely because the phone has been left running.

Replace an exercise when alternatives are available

When the screen offers Replace this exercise, tap it to open the available alternatives. The workout pauses while you choose. Selecting a movement changes the current exercise while keeping its set count, repetitions, rest and remaining timed interval. It does not restart the whole session.

If you opened the list from a running session, closing it resumes the session. If it was already paused, it stays paused. Home workout alternatives are filtered to equipment-free movements; no-jump and standing routines also keep their format restrictions.

The button is only shown when the current exercise has an available alternative. This also applies to home sessions in the flexible plan. The replacement control is not offered in the strength programs. A replacement changes the movement in this session; it does not recalculate the training load or make two different movements equivalent.

Return to the app after an interval finishes in the background

If the current interval reaches its end while Tonus is in the background, the session waits for you to confirm the next step. It does not silently fast-forward through later exercises and mark them done.

Open Tonus and use the control shown for the current phase to continue. Do not assume that leaving the app in the background will complete the rest of the workout.

Confirm the result at the end

After the last exercise, the difficulty screen lets you rate the session. Confirm the result to save the completed workout in Tonus. You can then review it in the app’s activity and progress views.

This guide describes the controls in Tonus 1.4. The app is free for iPhone with iOS 17 or later and does not require an account, subscription or in-app purchase.
